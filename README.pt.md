# Masthead

**Todas as notícias. Um só lugar tranquilo.**

Um elegante leitor de notícias para desktop que reúne as manchetes das principais redações de um país —
e deixa você lê-las sem anúncios, sem sair do aplicativo.
**Turquia · Estados Unidos · Índia · Reino Unido · Alemanha · Brasil · França.**

## Por que o Masthead?

Acompanhar as notícias costuma significar uma dúzia de abas no navegador, avisos de cookies, vídeos que começam
sozinhos e pop-ups. O Masthead reúne **955 redações de sete países** — a imprensa de cada país, no seu próprio idioma — em uma
única primeira página, tranquila e com cara de revista:

- **Acompanhe a agenda sem clicar.** Manchete completa, resumo e foto em cada cartão — a notícia principal traz
  o resumo inteiro, as outras terminam com “Resumo completo”. O **Resumo** reúne a mesma notícia publicada por
  veículos diferentes, assim você vê de relance quem disse o quê.
- **Leia ali mesmo, sem os anúncios.** Clique em uma notícia e ela abre em uma janela grande dentro do
  aplicativo — no **Modo de leitura** por padrão: a matéria em texto, na sua fonte de leitura. A página do
  veículo fica a um clique na mesma janela, com anúncios e rastreadores bloqueados. Pressione <kbd>Esc</kbd> e você volta.
- **Urgente, primeira página e uma linha do tempo ao vivo.** Um letreiro de notícias urgentes, uma manchete
  montada a partir das notícias que mais veículos estão publicando e uma coluna de “últimas”, minuto a minuto.
- **Suas fontes, suas regras.** Ligue ou desligue qualquer veículo. Filtre por período, fonte, ordem e
  imagem — e por região e cidade, estado ou área.
- **Notícias locais em todo lugar.** Escolha a sua cidade na Turquia, o seu estado no Brasil, nos EUA ou na Índia,
  o seu Land na Alemanha, a sua área no Reino Unido ou o seu departamento na França: os veículos de lá entram,
  com cada notícia nacional que cita o lugar.
- **Privado por princípio.** Sem conta, sem telemetria. Ajustes, notícias salvas e histórico ficam no seu computador.

### Leia a notícia, não o anúncio

Toda notícia abre dentro do Masthead, e o navegador interno roda com o **bloqueio de anúncios e rastreadores**
ligado (baseado no EasyList, dá para desligar em Ajustes → Leitura). Sem avisos de consentimento disputando a
sua atenção, sem vídeo que começa sozinho, sem pop-up de newsletter em cima do segundo parágrafo — a matéria, do
jeito que a redação escreveu. O bloqueio de anúncios só existe no aplicativo para desktop: na versão para
navegador a matéria aparece em um quadro incorporado ou no Modo de leitura, e só a própria página do veículo
pode bloquear alguma coisa.

**As notícias abrem no Modo de leitura**: manchete, assinatura e texto na sua fonte e no seu tamanho de leitura,
sobre o papel quente ou a tinta profunda do aplicativo. A mesma notícia, sem diagramação, sem scripts. Mude
para **Web** na barra de ferramentas quando quiser a página do próprio veículo — ou deixe a Web como padrão de
novo em Ajustes → Leitura. Downloads, pop-ups e pedidos de permissão das páginas de notícias são recusados, e o
navegador interno roda na sua própria sessão isolada, separada de todo o resto.

### Uma notícia, todos os veículos

O mesmo acontecimento raramente é contado da mesma forma duas vezes. O Masthead agrupa as notícias que redações
diferentes publicam sobre o mesmo fato, para você ver a notícia por vários ângulos em vez de enxergá-la por um
veículo só:

- Na **primeira página**, a notícia principal mostra quantos veículos estão publicando o mesmo fato
  (“8 fontes”) e, abaixo, as manchetes das outras redações.
- A página **Resumo** é essa ideia do começo ao fim: um cartão por acontecimento, o resumo mais completo no
  topo e, abaixo, a manchete de cada outro veículo com o logotipo e a hora em que publicou — a agenda do dia
  inteiro, sem clicar.
- Dentro de uma matéria aberta, **“Também publicado por”** lista o mesmo acontecimento em outros lugares: você
  pula da versão de uma redação para a de outra em um clique, ou percorre as notícias do dia com
  <kbd>Alt</kbd> + <kbd>←</kbd> / <kbd>→</kbd>.
- Ordene qualquer feed por **Mais publicadas** para deixar na frente as notícias que muitos veículos estão dando.

## Baixar

**No Windows, baixe pela Microsoft Store** (lá ele se chama *Masthead News*). A Microsoft assina a versão da Store,
então o Windows a instala sem o aviso do SmartScreen e a mantém atualizada em segundo plano.

<a href="https://apps.microsoft.com/detail/9PFZD4CRGSQV?mode=direct"><img src="assets/store/badge-pt.svg" width="200" alt="Obtenha na Microsoft" /></a>

Todo o resto está na [página de Releases](https://github.com/ahmetcaglayan/masthead/releases/latest):

| Plataforma | Arquivo |
| --- | --- |
| Windows (instalador, Intel/AMD) | `Masthead-x.y.z-win-x64.exe` |
| Windows (instalador, ARM) | `Masthead-x.y.z-win-arm64.exe` |
| Windows (portátil, sem instalação) | `Masthead-x.y.z-portable.exe` |
| macOS (Apple Silicon / Intel) | `Masthead-x.y.z-arm64.dmg` / `Masthead-x.y.z-x64.dmg` |
| Linux | `Masthead-linux-x86_64.AppImage` / `.deb` |

**Instale uma vez e ele se mantém atualizado.** O instalador do Windows e o AppImage do Linux procuram uma nova
versão a cada hora, baixam em segundo plano e pedem que você reinicie; o exe portátil, o app de macOS e o .deb
avisam quando sai uma nova versão. Desligue a instalação automática em Ajustes → Dados e sobre.

> **Os arquivos da página de Releases ainda não são assinados digitalmente.**
> - O SmartScreen do Windows pode avisar na primeira execução: escolha **Mais informações → Executar assim mesmo**.
> - Se o **Controle Inteligente de Aplicativos** (Smart App Control) estiver ligado (Windows 11 → Segurança do
>   Windows → Controle de aplicativos e navegador), o Windows pode simplesmente bloquear aplicativos não
>   assinados, sem a opção “Executar assim mesmo”. Use a versão para navegador abaixo, ou compile a partir do código-fonte.
> - macOS: na primeira vez, o macOS não abre o app. Vá em Ajustes do Sistema → Privacidade e Segurança e escolha
>   **Abrir Mesmo Assim**. (0.4.0 e anteriores podem aparecer como "danificado": rode `xattr -cr /Applications/Masthead.app` uma vez.)

### Não pode instalar programas? Rode no navegador

O aplicativo inteiro também roda em um navegador comum, na sua própria máquina — útil no computador do trabalho,
onde instalar programas não é permitido:

```bash
git clone https://github.com/ahmetcaglayan/masthead.git
cd masthead
npm install
npm run dev:web      # abra http://localhost:5173
```

No navegador, as notícias abrem em um quadro incorporado quando o site permite e, caso contrário, no Modo de
leitura (os navegadores impedem que a maioria dos sites de notícias seja incorporada; o aplicativo para desktop
não tem esse limite).

## Fontes

Cada país tem o seu **pacote de país** no Masthead: uma seleção de veículos politicamente equilibrada —
emissoras públicas, agências de notícias, jornais da grande imprensa, mídia independente, além de títulos de
negócios, esportes, tecnologia, saúde, viagem e cultura — e a imprensa local do país. Todo veículo escreve no
idioma do país: a Índia é lida pela sua imprensa em híndi, a Alemanha pelas suas redações alemãs, a França pelas francesas.

| País | Fontes | Feeds |
| --- | --- | --- |
| 🇹🇷 Turquia | 136 (67 nacionais + locais: feeds de cidade para todas as 81 províncias, jornais em 33 delas) | 536 |
| 🇺🇸 Estados Unidos | 227 (104 nacionais + 123 redações locais, duas ou três em cada estado e em D.C.) | 299 |
| 🇮🇳 Índia | 48, todas em híndi (40 nacionais + as páginas estaduais de oito jornais, 23 estados) | 263 |
| 🇬🇧 Reino Unido | 139 (71 nacionais + noticiário local da BBC para 51 áreas e 67 jornais regionais) | 251 |
| 🇩🇪 Alemanha | 154 (99 nacionais + notícias regionais dos 16 Länder, de 55 redações) | 249 |
| 🇧🇷 Brasil | 130 (95 nacionais + g1 para os 27 estados e 34 jornais regionais) | 221 |
| 🇫🇷 França | 121 (78 nacionais + France 3, ici e jornais regionais para os 101 departamentos) | 423 |

Todo feed é conferido no site do próprio veículo, no ar, antes de entrar (`npm run verify:feeds`). Veja
[docs/SOURCES.md](docs/SOURCES.md) para a lista completa, a estrutura do pacote de país e como adicionar a sua
própria fonte ou o seu próprio país.

O Masthead mostra as manchetes, os resumos e as imagens que os veículos oferecem nos seus feeds RSS públicos, com o
nome do veículo em cada cartão e um link para a página dele. O modo leitura monta a matéria a partir da página do
próprio veículo, baixada no computador de quem lê — nunca em matérias que o veículo reserva a assinantes.

### Para veículos

O Masthead é um leitor gratuito e de código aberto que roda no computador de cada pessoa. Não existe servidor do
Masthead: nada é republicado, guardado para terceiros ou vendido. Ele lê os feeds RSS que você publica, credita e
linka o seu veículo em cada notícia e deixa as matérias para assinantes no seu site (o modo leitura respeita
`isAccessibleForFree` e `article:content_tier`). Se preferir que o seu veículo não esteja incluído, ou quiser mudar
um feed, [fale com a gente](https://github.com/ahmetcaglayan/masthead/issues/new?labels=publisher&title=Publisher%20request%3A%20) e ele sai na próxima versão.

## Desenvolvimento

```bash
npm install
npm run dev          # aplicativo para desktop com recarga automática
npm run dev:web      # versão para navegador em http://localhost:5173
npm test             # testes unitários
npm run typecheck && npm run lint
npm run dist:win     # gera o instalador do Windows e o exe portátil em release/
```

Feito com Electron, React, TypeScript, Tailwind CSS e Vite. O backend (`src/core`) é Node.js puro e roda tanto
dentro do aplicativo para desktop quanto por trás do modo web. Leia [docs/PLAN.md](docs/PLAN.md) para conhecer
a arquitetura e o roadmap, e [CONTRIBUTING.md](CONTRIBUTING.md) para participar.

### Em uma rede que inspeciona o HTTPS

Em algumas redes corporativas, um proxy reassina toda conexão HTTPS com o certificado raiz da própria
organização. Os navegadores o aceitam pelo repositório de certificados do sistema, mas o Node.js mantém o seu
próprio — então todos os feeds falham com `SELF_SIGNED_CERT_IN_CHAIN` e o aplicativo fica vazio. Salve esse
certificado raiz em um arquivo PEM e aponte o Node para ele:

```bash
NODE_EXTRA_CA_CERTS=/path/to/root-ca.pem npm run dev:web
```

A mesma variável vale para `npm run dev`: as matérias são exibidas em um navegador incorporado, que usa o
repositório do sistema, mas os feeds são buscados pelo Node.

## Privacidade

Sem contas, sem analytics, sem rastreamento. O aplicativo só se conecta aos sites de notícias que você liga, ao
GitHub uma vez por hora para ver se saiu uma nova versão do Masthead e, se o bloqueio de anúncios estiver ligado,
baixa as listas de filtros públicas. Com a página Mercados aberta, busca cotações nas taxas de referência do Banco
Central Europeu (via Frankfurter), no gold-api.com e nos dados públicos de mercado da Binance; se você ligar o cartão
do tempo, o Open-Meteo recebe o nome e a posição da sua cidade. "Para você" aprende com o seu histórico de leitura no
seu computador. Veja [SECURITY.md](SECURITY.md).
